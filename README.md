**Подорожник — скачает, когда Диск не может.**

Небольшое приложение для macOS: скачивает публичную папку Яндекс Диска со всеми вложениями, повторяет неудачные попытки и продолжает загрузку после обрыва. Без Python, Терминала и входа в аккаунт.

[Скачать DMG](https://github.com/sirdimitry/plantain/releases/latest) · [Приватность](docs/PRIVACY.md)

## Как пользоваться

1. Перетащите **Plantain.app** из DMG в «Программы».
2. Вставьте публичную ссылку на папку или файл.
3. При необходимости выберите место сохранения. По умолчанию это «Загрузки».
4. Нажмите **«Скачать»**.

В выбранном месте появится папка с исходным названием и окончанием ` copy`. Вложенные и пустые папки сохраняются, файлы внутри — под своими именами. Если ссылка ведёт на один файл, он тоже сохраняется под своим именем: `video.mp4`.

macOS 13 и новее, Apple Silicon и Intel. Пользователям Python не нужен. Сборка имеет локальную подпись и не прошла нотариальную проверку Apple; при первом запуске macOS может потребовать разрешить приложение в настройках безопасности.

## Возможности

- Прогресс текущего файла и всей папки: объём, скорость, примерное оставшееся время и количество файлов.
- Проверка всех готовых файлов по размеру и контрольной сумме (если сервер её отдаёт) до начала скачивания. **«Уже есть»** сразу учитывает найденные файлы. Без хеша файл проверяется только по размеру, и итог загрузки говорит об этом отдельно.
- До 20 попыток на файл, с паузами и обновлением ссылки скачивания.
- Докачка после остановки, если сервер поддерживает диапазоны.
- Существующие файлы с другим содержимым не перезаписываются.

Для продолжения после закрытия приложения введите ту же ссылку и выберите прежнее место. Закрытые папки не поддерживаются. Не запускайте две загрузки одной папки одновременно.

## Приватность

Ссылка и выбранная папка живут только в памяти текущего сеанса. При новом запуске поле ссылки пустое, место сохранения — «Загрузки».

Нет истории загрузок, аналитики, отправки логов, постоянных отчётов об ошибках, cookies и постоянного сетевого кэша. На диске остаются скачанные файлы и частичные данные для докачки в `.diskloader-partials`. Их технические имена основаны на размере и контрольной сумме содержимого, без ссылки и выбранного пути.

В About — слоган и две кнопки публичных профилей автора. Сайты открываются только по нажатию. [Подробнее](docs/PRIVACY.md).

## Сборка из исходников

Требуются macOS и Xcode Command Line Tools. Внешних Swift-зависимостей нет.

```bash
xcode-select --install
git clone https://github.com/sirdimitry/plantain.git
cd plantain
./scripts/build.sh
```

Результат: `dist/Plantain.app`, универсальная сборка для Apple Silicon и Intel. Для DMG:

```bash
./scripts/build.sh --dmg
```

## Проверки

Для локального тестового сервера требуется Python 3. Самому приложению он не нужен.

```bash
./scripts/test.sh
```

37 проверок: целостность, докачка, игнорирование диапазонов сервером, остановка, повторный запуск, пустые папки, сохранность существующих файлов, имена результатов, файлы без контрольных сумм, коды ответов сервера, очистка старых настроек и ограничения сети. Тесты работают с локальным сервером на свободном порту и не используют личные ссылки или аккаунты.

Проверено на Apple Silicon. Версия Intel собирается, но на физическом Intel Mac не проверена.

## Структура

- `Sources/` — SwiftUI-приложение и загрузчик.
- `Assets/` — иконка, баннер, локальный значок GitHub.
- `scripts/` — сборка приложения, DMG и запуск проверок.
- `Tests/` — проверки и локальный HTTP-сервер.

## Независимый проект

Подорожник не связан с Яндексом и не является официальным клиентом. Логотипы и фирменная иконка Яндекс Диска не используются. Надгробие, латинская надпись RIP и подорожник составляют самостоятельную иллюстрацию. Это описание дизайна, а не юридическая гарантия.
