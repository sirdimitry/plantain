# Сторонние материалы

- Значок GitHub взят из официального набора: https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png. GitHub и его знак принадлежат их правообладателю.
- Значок X используется только для ссылки на профиль и нарисован локальной векторной фигурой.
- Иконка приложения и баннер созданы для проекта с помощью ImageGen. Они не включают официальную иконку Яндекс Диска или логотип Яндекса.
- Используются системные SwiftUI, AppKit, Foundation и CryptoKit. Внешних исполняемых зависимостей в приложении нет.
