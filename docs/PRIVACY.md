# Приватность

Ссылка и выбранная папка используются только в памяти текущего сеанса. Они не записываются в настройки, историю, журнал, отчёт или Keychain. После нового запуска ссылка пуста, место сохранения — «Загрузки».

Очищается старая сохранённая ссылка и история диалога выбора папки предыдущих версий. Восстановление содержимого окон отключено. Геометрия окна может сохраняться macOS, без поля ссылки и пути.

## Сеть

При скачивании ссылка передаётся API Яндекса. Локальная папка ему не передаётся. Используются HTTPS и стандартная проверка TLS. Перенаправления скачивания ограничены доменами Яндекса. Внешние поддельные домены и переход на HTTP отклоняются.

Сессии `URLSessionConfiguration.ephemeral` дополнительно настроены без сетевого кэша, cookies и хранилища учётных данных. Аналитики, рекламы и автоматической отправки логов нет.

GitHub и X из About открываются в браузере только по нажатию. Значки находятся внутри приложения, а не загружаются из сети.

## На диске

Скачанные файлы и незавершённые данные для докачки. `.diskloader-partials` рядом с результатом содержит только частичные данные. Технические имена основаны на размере и контрольной сумме содержимого. Ссылка, её хеш и выбранный путь в них не входят.

После успешного скачивания частичный файл удаляется. Пустая служебная папка также удаляется. При остановке данные остаются для продолжения. Без контрольной суммы безопасная докачка между попытками не используется.

Сообщения об ошибках остаются только в окне текущего сеанса. Сами скачанные файлы и структура результата по необходимости остаются в выбранной папке.

## Границы

Правила относятся к приложению. Политика не обещает отсутствие системных диагностических записей macOS, истории браузера при открытии профилей или пользовательских снимков экрана.

Локальная подпись не равна нотариальной проверке Apple. Автоматические проверки не гарантируют отсутствие любых уязвимостей.
