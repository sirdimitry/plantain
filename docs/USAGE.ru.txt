Подорожник — скачает, когда Диск не может

macOS 13 и новее. Apple Silicon и Intel. Python не требуется.

Перетащите Plantain в Applications («Программы»).
Вставьте публичную ссылку на папку или файл Яндекс Диска и нажмите «Скачать».
Место сохранения можно выбрать; по умолчанию это «Загрузки».
Внутри появится папка с исходным названием и окончанием copy.
Файлы внутри сохраняются под своими именами; один файл по ссылке — тоже.

Уже скачанные файлы проверяются и сразу учитываются в прогрессе.
Для остановки нажмите «Остановить». Для продолжения после перезапуска
введите ту же ссылку и выберите прежнее место.
Ссылка и выбранная папка не запоминаются. Cookies, HAR и вход не нужны.
Для докачки сохраняются только частичные данные в .diskloader-partials.
Не запускайте две загрузки одной папки одновременно.

Сборка имеет локальную подпись, без нотариальной проверки Apple.
При первом запуске macOS может потребовать разрешение в настройках
«Конфиденциальность и безопасность».

Исходники и обновления: https://github.com/sirdimitry/plantain
