# Безопасность

Не публикуйте в issues и pull requests HAR, cookies, токены, приватные ссылки, имена личных файлов или полные пути с компьютера. Используйте синтетические данные и локальный сервер из `Tests/`.

Если проблема требует секретных данных, не прикладывайте их к публичной задаче. Отдельный закрытый канал для сообщений об уязвимостях пока не настроен.

Сборки имеют локальную подпись; нотариальная проверка Apple не выполняется. Проверяйте источник скачивания. Контрольные суммы публикуются вместе с релизом: `./scripts/build.sh --dmg` создаёт рядом с DMG файл `.sha256`.
