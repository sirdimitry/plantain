# Подорожник для Windows

Подорожник — скачает, когда Диск не может.

**Версия материалов Windows: 0.1.0-dev.1. Статус: этап 1 завершён — требования и критерии приёмки.**

Исполняемого приложения, результатов его тестирования и установщика пока нет. Номер обозначает предварительный этап разработки, а не готовый выпуск. Будущее приложение будет скачивать публичные файлы и папки Яндекс Диска с проверкой целостности и безопасной докачкой.

Есть готовая [версия для macOS](https://github.com/sirdimitry/plantain/blob/main/README.md), сейчас 1.1.1. [Скачать macOS DMG](https://github.com/sirdimitry/plantain/releases/tag/v1.1.1). Код macOS находится в `main`; Windows разрабатывается в отдельной ветке `windows` того же репозитория.

## План реализации

Целевая первая платформа — Windows 11 x64. Предлагаемый стек — C# / .NET 10 LTS, WPF. Далее: независимый загрузчик и его тесты, работа с файлами Windows, интерфейс, проверка на реальном компьютере, portable-сборка. ARM64 требует отдельной проверки. Установщик будет отдельным этапом позже.

Сейчас нет команд сборки и запуска: C#-проект ещё не создан. Не следует запускать macOS-скрипты из корня для сборки Windows.

## Проверки на этом этапе

Проведена сверка спецификации с исходниками macOS и проверка документации, ссылок, версии и отсутствия изменений Swift-кода. Конкретные результаты записаны в [журнале изменений](CHANGELOG.md). Тесты приложения не запускались: Windows-реализации ещё нет, а текущие Swift-тесты предназначены для macOS. Упоминание 37 проверок исходной версии не означает, что Windows их уже проходит.

## Приватность и ограничения

В спецификации сохранены отсутствие истории ссылок, cookies, постоянного сетевого кэша и отправки логов; реализованность будет проверяться отдельно. Планируемая докачка без контрольной суммы между попытками отключена. Некоторые имена Яндекс Диска несовместимы с Windows: такие конфликты будут показываться явно, без скрытого переименования и перезаписи.
