# Установщик Windows

Установщик `Plantain-<версия>-win-x64-Setup.exe` предназначен для Windows 10 версии 1607 и новее и Windows 11 x64. Среда .NET 10 включена: установка не скачивает зависимости и не требует Python, SDK или обязательных прав администратора. Windows 7/8.1 и 32-битные Windows не поддерживаются. На Windows 11 ARM64 установщик допускает x64-эмуляцию, но она не проверялась.

Минимальная версия ОС задана явно (`MinVersion=10.0.14393`), архитектура проверяется до копирования файлов. Это техническая нижняя граница, а не обещание проведённых испытаний на каждой версии. Фактические результаты — в [отчёте](TEST-RESULTS.ru.md). Официальная поддержка .NET зависит также от срока поддержки самой редакции Windows: [требования Microsoft](https://learn.microsoft.com/en-us/dotnet/core/install/windows).

## Установка и обновление

1. Скачайте `Setup.exe` с [Windows-релиза](https://github.com/sirdimitry/plantain/releases/tag/windows-v0.1.0-dev.8).
2. Запустите установщик и следуйте мастеру. Можно выбрать папку; по умолчанию — `%LOCALAPPDATA%\Programs\Plantain`.
3. Открывайте «Подорожник» из меню «Пуск». Ярлык рабочего стола — необязательная опция мастера.

Для обновления закройте программу и запустите новый установщик. Постоянный AppId сохраняет путь, ярлыки и единственную запись в списке приложений. Переустановка той же версии разрешена, установка старой поверх новой блокируется. Если приложение работает, установка и удаление предлагают сначала закрыть его; принудительное завершение загрузки отключено. Автоматической установки из приложения пока нет — уведомление открывает официальный релиз GitHub.

Удаление доступно через «Параметры → Приложения → Подорожник». Удаляются установленные компоненты, созданные ярлыки и запись программы; скачанные файлы и `.diskloader-partials` в выбранной папке загрузок сохраняются.

Файлы .NET лежат в подпапке `app`, рядом с приложением. Это обычная автономная установка: библиотеки не извлекаются во временный каталог при каждом запуске. Portable ZIP по-прежнему содержит один EXE и инструкцию.

Установщик пока не имеет собственной цифровой подписи издателя; Windows может показывать «Неизвестный издатель» или предупреждение SmartScreen. SHA-256 публикуется рядом с Setup.exe и ZIP. Подпись и репутация Windows — отдельный следующий шаг; установщик не меняет настройки защиты компьютера.

## Сборка

Нужны .NET 10 SDK и [Inno Setup 7.1.1](https://jrsoftware.org/isdl.php). Inno — только инструмент разработчика; пользователю устанавливать его не нужно. Локальный путь компилятора — `windows/.tools/inno-7.1.1/ISCC.exe`; также принимается `installer.ps1 -Iscc 'путь\ISCC.exe'` или ISCC из PATH. Автоматической загрузки/запуска компилятора сборочный скрипт не выполняет.

Официальный дистрибутив компилятора `innosetup-7.1.1-x64.exe` проверен по SHA-256 GitHub `8a5a6711c3766a6e5fb74f280ba0e3551e719ce94538d901fdbd1f8f9920b3f0` и действительной подписи Pyrsys B.V.

Из корня репозитория:

```powershell
.\windows\scripts\installer.ps1
.\windows\scripts\publish.ps1
.\windows\scripts\release.ps1
```

`installer.ps1` читает `windows/VERSION`, включает Git-ревизию в приложение, собирает автономную папку .NET x64 и вызывает [Plantain.iss](../installer/Plantain.iss). Версия ресурса Windows — `major.minor.patch.dev`, для стабильного выпуска последняя часть равна 65535; отображаемая версия сохраняет SemVer. Значок встроен и в EXE приложения, и в Setup.exe. [Файлы оформления и промпт баннера](../installer/assets/README.md).

Результаты: `windows/artifacts/packages/<ревизия>/Plantain-<версия>-win-x64-Setup.exe`, его `.sha256` и `installer-build.json`. В грязной рабочей копии ревизия помечается `-dirty`; для публикации нужны чистый коммит и его собственные Setup/ZIP. Публикация явно: `release.ps1 -Publish`; добавляются Setup, ZIP и обе контрольные суммы. Общий latest macOS сохраняется.

## Проверка установщика

```powershell
.\windows\scripts\test-installer.ps1 -Setup 'путь\Setup.exe'
# Дополнительно — реальное обновление с более старого установщика:
.\windows\scripts\test-installer.ps1 -Setup 'путь\новый-Setup.exe' -PreviousSetup 'путь\старый-Setup.exe'
```

Скрипт останавливается, если уже есть установленная программа, её запись версии, ярлык рабочего стола или запущенный процесс: существующая пользовательская установка не перезаписывается. Для повторяемой проверки нужен отдельный пользователь/VM либо компьютер без установленного Подорожника. Испытание устанавливает в собственную папку с кириллицей и пробелами, проверяет ярлыки, регистрацию, обновление/переустановку, защиту от понижения версии и замены работающего приложения, локальную среду .NET и удаление с сохранением контрольного пользовательского файла. Локальный отчёт — `windows/artifacts/installer-tests/<идентификатор>/result.json`.
