Подорожник для Windows — предварительная автономная сборка x64

Распакуйте ZIP целиком в отдельную папку и запустите Plantain.Windows.exe.
В архиве один файл приложения и эта инструкция. Среда .NET встроена.
При первом запуске необходимые нативные библиотеки извлекаются в
системную временную папку .NET; следующие запуски используют их повторно.
Устанавливать .NET, SDK или Python отдельно не требуется.
Программа запускается без прав администратора. Установщика пока нет.

При запуске проверяются новые Windows-версии в GitHub. Если версия новее,
появится синее окно. «Скачать обновление» откроет Windows-релиз в браузере;
скачайте новый ZIP и распакуйте его целиком в отдельную папку.
«Позже» закрывает предложение до следующего запуска. Автоустановки нет.

Вставьте публичную ссылку Яндекс Диска, выберите папку и нажмите «Скачать».
После полного успеха ссылка очистится. Красный «!» открывает список
незавершённых файлов с расширениями и причинами. При остановке ссылка
остаётся для продолжения. Существующие конфликтные файлы не заменяются.

Версия указана в «О программе». Ссылки и выбранная папка не сохраняются
самим приложением. Незавершённые данные остаются в .diskloader-partials.

Это предварительная сборка: расширенная проверка внешних/сетевых томов,
больших файлов, экранного диктора и разных мониторов ещё продолжается.
Целевая система — Windows 11 x64. ARM64 отдельно не проверена.

До 5 попыток на файл с отсчётом до повтора. «Пропустить» переходит
к следующему файлу; пропущенный остаётся в списке красного «!».
Скорость — Мбит/с, размеры — десятичные МБ/ГБ.
