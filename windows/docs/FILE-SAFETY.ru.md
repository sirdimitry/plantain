# Файловая защита Windows — 0.1.0-dev.3

Реализация: [WindowsFiles.cs](../src/Plantain.Core/WindowsFiles.cs), [DownloadEngine.cs](../src/Plantain.Core/DownloadEngine.cs). Проверки: [FileSafetyTests.cs](../tests/Plantain.Core.Tests/FileSafetyTests.cs). На этом этапе проверена Windows x64 и NTFS; реальные другие файловые системы пока не подтверждены.

## Привязка к объектам

Цепочка каталогов открывается от корня тома до выбранного назначения. Каждый дочерний каталог и файл открывается одним компонентом относительно дескриптора родителя через NtCreateFile, с OBJ_DONT_REPARSE и FILE_OPEN_REPARSE_POINT. Проверяются атрибуты полученного объекта. Это исключает повторное разрешение полного пути между проверкой и записью; текстовые пути нужны для инвентаризации и сообщений, а не для повторного открытия файла при публикации.

Родители удерживаются без FILE_SHARE_DELETE, поэтому их нельзя переименовать или удалить до завершения сеанса. Совместная запись в каталог допускается: она нужна нормальным файловым операциям. Защита от переадресации обеспечивается относительным открытием по дескриптору, а не предположением, что атрибут reparse никогда не изменится. Перед новой операцией атрибут родителя проверяется ещё раз. Поздняя установка junction проверена отдельным тестом: внешняя цель не изменяется.

Partial открывается без совместного доступа, без усечения при открытии и с правом DELETE. До записи проверяется, что это обычный файл, не reparse point и число жёстких ссылок равно единице. Файл не закрывается между передачей, хешированием и переименованием. Обнуление при отсутствии хеша, HTTP 416 или неверной сумме выполняется по этому же дескриптору. Проверка готового локального файла тоже использует удерживаемый объект с запретом конкурентной записи/удаления.

Публикация — NtSetInformationFile / FileRenameInformation относительно дескриптора целевой папки, ReplaceIfExists=false. Проверенный источник не ищется заново по имени; существующая цель вызывает ошибку. Копирования с перезаписью и удаления чужого файла нет. Нативные файловые дескрипторы синхронные, чтобы результат операции и время жизни служебных структур были окончательными при возврате; FileStream предоставляет отменяемые асинхронные операции с байтами.

## Блокировка назначения

Каталог .diskloader-partials открывается с правом DELETE и без совместного удаления. Второй движок с тем же назначением не может получить такой дескриптор, даже из другого процесса. Блокировка относится к объекту каталога, а не только к строке пути. Она освобождается при dispose или завершении процесса, в том числе принудительном. Файл-маркер, история URL и сохранённый путь не нужны.

Пустой cache помечается к удалению по собственному дескриптору. Если он не пуст или удаление недоступно, он остаётся для продолжения. Рекурсивного удаления и удаления по заново разрешённому пути нет. Готовые пользовательские папки не удаляются.

## Имена и изоляция ошибок

До записи группируются все имена одного удалённого каталога без учёта регистра. При коллизии не выбирается победитель по порядку API: обе стороны получают ошибку. Недопустимое имя или конфликт каталога исключает его поддерево; допустимые соседи продолжают скачиваться. Автоматического переименования нет. Имя корневого результата не может совпадать со служебной папкой.

Files/Bytes относятся к известным файлам, включая известные заблокированные файлы. Необойдённое конфликтное поддерево имеет собственную ошибку, число файлов в нём неизвестно и не выдумывается. Даже при Done=Files наличие ошибки каталога означает частичный результат. Ошибки доступа, read-only, блокировки и неподдерживаемой операции не повторяются как сетевые сбои.

Размер компонента ограничен 255 UTF-16 единицами; длинный полный путь поддерживается относительными операциями и проверен на NTFS. Для FAT32 есть ранняя проверка предела 4 ГиБ минус 1 байт. Наличие этого правила и Windows API не означает проверенную совместимость с реальными exFAT/FAT32/SMB: это остаётся отдельной приёмкой. Если файловая система не поддерживает нужную безопасную операцию, она не заменяется небезопасным способом.
