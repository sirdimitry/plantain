Подорожник для Windows

Открывайте программу ярлыком «Подорожник» в меню «Пуск».
Ярлык на рабочем столе можно выбрать при установке.

Вставьте публичную ссылку Яндекс Диска, выберите папку и нажмите «Скачать».
Красный «!» открывает список незавершённых файлов. «Пропустить» переходит
к следующему файлу; частичная загрузка остаётся для продолжения.

Среда .NET включена в установщик. Python и права администратора не нужны.
Библиотеки приложения находятся в подпапке app; не переносите их отдельно.
Установка работает без интернета, скачивание файлов требует подключения.

Обновление: скачайте новый Setup.exe с официального Windows-релиза GitHub,
закройте Подорожник и установите поверх прежней версии. Загрузки сохранятся.
Удаление: Параметры Windows → Приложения → Подорожник → Удалить.
Удаление программы не удаляет скачанные файлы и .diskloader-partials
в выбранной вами папке загрузок.

Windows 10 версии 1607 и новее / Windows 11, x64.
На Windows 11 ARM64 возможен запуск x64 через эмуляцию; он не проверялся.
32-битные Windows, Windows 7 и 8.1 не поддерживаются.
Фактически проверено на Windows 11 x64; другие системы требуют проверки.
