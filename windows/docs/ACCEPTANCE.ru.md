# Матрица приёмки Windows

Этап 2, 0.1.0-dev.2: **75/75 автоматических проверок независимого движка пройдено**. B01–B17 проверены на локальном сервере; B18 — события движка, без расчётов будущего UI. W02/W03 имеют только базовые отрицательные проверки; W05 проверен на NTFS, W07 — классификация и реальная блокировка файла. W10 частично: потоковая обработка 8 МиБ без UI и больших реальных файлов. Остальные W-сценарии, полный объём W02/W03 и реальные файловые системы отложены. [Подробности и ограничения](TEST-RESULTS.ru.md).

Обозначения B — перенос поведения исходника, W — дополнительные требования Windows. Строки ниже задают целевую приёмку, а не утверждают выполнение всех пунктов. README macOS заявляет 37 проверок, но они не запускались; Windows использует собственный набор.

| ID | Сценарий | Условие приёмки |
| --- | --- | --- |
| B01 | Папка, вложенность, пустые папки; отдельный файл | Структура совпадает; copy только у корневой папки, расширение файла сохранено |
| B02 | Несколько страниц API, отсутствующий total, преждевременно пустая страница | Полный список без потерь либо явная ошибка неполного списка |
| B03 | Все имеющиеся файлы | Проверены до первого скачивания, байты и «Уже есть» учтены сразу |
| B04 | SHA-256 и MD5, повреждение при том же размере | Верные файлы приняты, повреждение обнаружено; SHA-256 приоритетнее |
| B05 | Нет хеша: имеющийся и новый файл | Размер принят, итог явно отделяет проверку только по размеру |
| B06 | Нет хеша: старый partial | Новая попытка начинается с нуля; данные разных ответов не склеиваются |
| B07 | Range поддерживается | Получен точный исходный файл из старого префикса и нового диапазона |
| B08 | Range проигнорирован, неверный Content-Range, HTTP 416 | Безопасный перезапуск/отказ, без испорченного итогового файла |
| B09 | Ответ короче или длиннее размера; неверный хеш | Нет публикации повреждённого результата, корректный повтор |
| B10 | Полный partial и файл нулевой длины | Проверка и публикация без ненужной передачи |
| B11 | Отмена при передаче, проверке и ожидании повтора | Быстрая остановка; файлы закрыты, пригодный partial сохранён |

| B13 | Уже существующий файл отличается | Содержимое не изменено, показан конфликт, другие файлы обработаны |

| B16 | Небезопасная ссылка/redirect и неверный TLS-сертификат | Отказ до передачи данных на запрещённый адрес |
| B17 | Приватность | Нет сохранённых ссылок, cookies, сетевого кэша, учётных данных и отчётов; имя partial основано только на размере/хешах |
| B18 | Прогресс, ошибка части файлов, пустая папка | Честный итог, нет двойного счёта; полная готовность только при успехе |
| W01 | Кириллица, emoji, длинный путь, глубокая вложенность | Корректная запись либо понятное ограничение без повреждения данных |
| W02 | CON.txt, NUL, COM1, ADS, управляющие символы, точки/пробелы в конце | Явный конфликт до записи, без скрытого переименования |
| W03 | Фото.jpg и фото.jpg; файл/каталог с одним именем | Оба конфликтующих объекта выявлены заранее, ничего не перезаписано |
| W04 | .., абсолютный/UNC/drive-relative путь, junction/reparse point | Запись не выходит из разрешённого назначения, включая гонку подмены |
| W05 | Другой процесс создал итоговый файл во время передачи | Итоговый файл сохранён без изменений, partial остаётся пригодным |

| W09 | Принудительное завершение процесса, пропадание сети | После запуска проверяется partial, готовое не повреждено |

| W11 | Масштаб 125/150/200%, темы, клавиатура, экранный диктор | Все действия и статусы доступны, текст и кнопки не обрезаны |
| W12 | Перенесённые/недоступные «Загрузки», история диалога | Корректное назначение либо выбор папки; поведение приватности проверено |
| W13 | Автосон, ручной сон, закрытие окна | Запрет автосна только во время работы; корректная остановка и восстановление |
| W14 | Чистая Windows 11 x64 без SDK и установленного .NET | Будущая portable-сборка запускается и скачивает файл |

## Как получать доказательства

Для B-сценариев — автоматические тесты движка с контролируемым HTTP-сервером и синтетическими данными. [Существующий сервер](../../Tests/server.py) служит поведенческим ориентиром и не изменяется. В этапе 2 написан [собственный HTTP/TLS-сервер C#](../tests/Plantain.Core.Tests/TestServer.cs), чтобы не требовать Python и проверять заголовки, задержки и TLS в одном процессе. Проверяются байты/хеши, число запросов, события и сохранность конфликтующих файлов; паузы подменяются IRetryDelay, без ожидания реальных многосекундных повторов.

Для W-сценариев — автоматические проверки там, где возможно, и отдельная ручная проверка на реальной Windows. В результате указывать версию приложения, коммит, ОС/архитектуру, тип тома, выполненные сценарии, ошибки и ограничения. Не подменять реальную проверку накопителя моками. Личные ссылки не включать в репозиторий или отчёты.

## Завершение этапов

Этап 1 завершён, когда контракт сверён с исходниками, отличия Windows отделены от текущего поведения, определены проверки, версии разделены, два README связаны и документационные проверки проходят. Это не разрешение на релиз приложения.

Движок готов к подключению UI после прохождения относящихся к нему B/W-сценариев. Первая публичная portable-сборка готова после проверки интерфейса, реальной Windows, файловых систем и чистого компьютера с явным списком оставшихся ограничений. Установщик готовится позже отдельным решением.
