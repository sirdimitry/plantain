# Изменения Windows

## 0.1.0-dev.2 — 2026-10-30

Этап 2: добавлена независимая библиотека Plantain.Core (.NET 10, без внешних пакетов). Реализованы API и пагинация, потоковая передача, SHA-256/MD5, проверка имеющихся файлов, докачка, отмена, ограниченные повторы, раздельные таймауты, события прогресса и публикация без замены существующего файла. Сетевой слой проверяет все redirect-адреса, не принимает поддельный TLS-сертификат, не хранит cookies и не включает сетевые учётные данные.

Добавлены 75 автономных тестов с локальным HTTP/TLS-сервером, скрипт запуска и JSON-отчёт. Версия сборки читается из windows/VERSION; скрипт добавляет реальный Git-хеш и dirty. Обновлены оба README; в main изменена только документация о стадии Windows (62839d2). Swift-код, macOS-тесты/скрипты/ресурсы/документы и корневой VERSION не менялись.

Результат: 75/75, Release-сборка без предупреждений и ошибок, Windows x64 (build 26200), NTFS, SDK 10.0.403. Проверены также потоковая обработка до окончания ответа, связка API с движком, отмена на границе проверки и реальная блокировка файла Windows. Подробности — [отчёт этапа](docs/TEST-RESULTS.ru.md).

Ограничения: нет UI и установщика, не проверен живой API; защита от подмены пути и параллельных запусков, обработка конфликтных поддеревьев, exFAT/SMB и большие реальные загрузки относятся к следующим этапам. Тег и GitHub Release не создаются.

## 0.1.0-dev.1 — 2026-10-30

Первый этап: зафиксированы требования к переносу macOS 1.1.1, матрица приёмки, отличия файловой системы Windows и правила разработки. Добавлен отдельный README Windows со ссылкой на macOS; README macOS получил ссылку на Windows в документационном коммите `ea0c27c`.

Кода приложения и установщика пока нет. Swift-код, его тесты, скрипты и корневой VERSION не изменены.

Проверки: сверка требований с Core.swift, Privacy.swift, App.swift и CoreTests.swift; git diff --check; проверка локальных Markdown-ссылок и согласованности номера Windows; сравнение дерева macOS с исходным коммитом. Результат: проверки документации пройдены. Тесты приложений и сборки не выполнялись. Публикация в ветке windows не является выпуском приложения; тег релиза не создаётся.
