# Изменения Windows

## 0.1.0-dev.6 — 2026-10-30

Этап 6: фоновая проверка Windows-обновлений GitHub при запуске. Синее окно показывает новую/установленную версии, «Скачать обновление» и «Позже». Кнопка открывает официальный Windows-релиз; ZIP распаковывается вручную. Проверка не мешает загрузке, откладывает предложение до её завершения и молчит при недоступной сети. При закрытии запрос отменяется.

Windows отделена от macOS префиксом windows-v и точными именами ZIP/SHA-256. Есть SemVer, пагинация, лимиты времени/размера, отсечение черновиков, старых версий и ARM64-вложений. GitHub API вызывается без токена/cookies; ссылка Яндекс Диска и выбранная папка не передаются. Добавлены инструкция и скрипт явной публикации Windows-релиза без смены общего latest macOS.

Результат: 122/122 проверки движка, включая 21 сценарий обновлений; 25/25 WPF. Просмотрен рендер синего окна, проверены один показ за запуск, «Позже», явное открытие нужной страницы, отмена запроса при закрытии и задержка уведомления до окончания загрузки. Реальный GitHub API проверен: macOS-релизы не предложены в Windows. Автоустановки нет; публичный Windows-релиз автоматически не создавался. Swift-код и macOS VERSION=1.1.1 не менялись.

## 0.1.0-dev.5 — 2026-10-30

Быстрый этап 5: добавлена автономная публикация win-x64 со встроенными .NET/WPF, ZIP и SHA-256. Новый scripts/publish.ps1 разделяет артефакты по Git-ревизии и не перезаписывает существующий архив. В архив входит инструкция. Код приложения не изменён; прежние 101+20 проверок и реальное скачивание двух файлов относятся к этапу 4. Для этапа 5 отдельно проверяются состав пакета, запуск и загрузка coreclr.dll из папки portable.

Это предварительная автономная сборка, не установщик и не стабильный релиз. Полная приёмка на чистой машине, exFAT/FAT32/SMB, больших файлах, другом DPI и экранном дикторе остаётся незавершённой. Версия macOS 1.1.1 и Swift-код не меняются.

## 0.1.0-dev.4 — 2026-10-30

Этап 4: добавлено WPF-приложение Plantain.Windows с полем ссылки, системными «Загрузками» и выбором папки, открытием Проводника, прогрессом, скоростью/ETA, остановкой и продолжением. Закрытие окна ожидает остановки; запрос предотвращения автосна освобождается при завершении. Добавлены обе темы, системные цвета высокого контраста, клавиатура, окно «О программе» и ссылки автора/macOS. Полный успех очищает поле и отключает «Скачать»; смена назначения сбрасывает старые итоги.

По запросу пользователя добавлен белый «!» в красном круге. Он открывает виртуализированную таблицу незавершённых файлов: исходное имя с расширением, относительный путь и причина. После отмены показываются известные недокачанные файлы, готовые исключаются. Недоступные поддеревья обозначаются папками. Повторное открытие не создаёт дубликаты окон; фокус возвращается к кнопке. Движок передаёт события обнаружения, завершения и ошибки файла, чтобы список не зависел только от итогового исключения.

Результат: 101/101 проверка движка и 20/20 WPF, Release без предупреждений/ошибок. Собраны .exe и необходимые соседние файлы в windows/artifacts/app. Нативный запуск и диалог папки проверены. По предоставленной пользователем ссылке скачаны 2 файла (1 314 364 байта), обе SHA-256 совпали с API; повтор показал «Уже есть: 2». В отдельном конфликтном назначении существующий тестовый файл не изменился, второй скачался и прошёл SHA-256, красный значок показал имя .mp4 и причину. Ссылка не добавлена в репозиторий или сохранённые отчёты.

Обновлены оба README. Swift-код, macOS-тесты/скрипты/ресурсы/документы и VERSION=1.1.1 не менялись. Текущая сборка требует .NET 10 Desktop Runtime; автономная упаковка и установщик отложены. Полная приёмка exFAT/FAT32/SMB, больших файлов, физического DPI и экранного диктора остаётся впереди. AddToRecent отключён, очистка GUID-состояния диалога выполняется по возможности: E_FAIL оболочки не считается подтверждением очистки. [Результаты](docs/TEST-RESULTS.ru.md).

## 0.1.0-dev.3 — 2026-10-30

Этап 3: файловые операции Windows переведены на удерживаемые дескрипторы. Потомки открываются относительно проверенного родителя через NtCreateFile, без повторного разрешения полного пути и обхода reparse points. Каталоги удерживаются без совместного удаления; partial остаётся одним открытым объектом во время передачи, проверки и NtSetInformationFile-публикации без замены. Частичные файлы с жёсткими ссылками отклоняются до изменения содержимого. Очистка пустой служебной папки выполняется по дескриптору, без рекурсивного удаления.

Блокировка папки назначения основана на несовместимом совместном доступе к дескриптору .diskloader-partials: второго движка не пускает Windows; завершение процесса освобождает блокировку без постоянного lock-файла. Недопустимые имена и обе стороны коллизии пропускаются с ошибками, допустимые файлы продолжают скачиваться. Добавлены ограничение FAT32 и длинные Unicode-пути.

По запросу пользователя добавлена модель сеанса Windows: полный успех очищает источник и отключает повторную кнопку «Скачать», итог остаётся; отмена и ошибки сохраняют ссылку для продолжения. В macOS это поведение не менялось. UI ещё не создан.

Результат: 101/101 проверка (75 базовых, 19 файловых, 7 сеанса), Release без предупреждений/ошибок, Windows x64, NTFS, SDK 10.0.403. Есть тест реального отдельного процесса с принудительным завершением, снятием блокировки и докачкой. Обновлены оба README. Swift-код, его тесты/скрипты/ресурсы/документы и версия 1.1.1 не менялись.

Ограничения: здесь доступны только NTFS-тома; реальные exFAT/FAT32/SMB, ARM64, многогигабайтная передача, перезагрузка ОС и интерфейс не проверены. Проверка FAT32 — тест правила, не реального накопителя. [Подробности](docs/TEST-RESULTS.ru.md). Установщик и выпуск не создаются.

## 0.1.0-dev.2 — 2026-10-30

Этап 2: добавлена независимая библиотека Plantain.Core (.NET 10, без внешних пакетов). Реализованы API и пагинация, потоковая передача, SHA-256/MD5, проверка имеющихся файлов, докачка, отмена, ограниченные повторы, раздельные таймауты, события прогресса и публикация без замены существующего файла. Сетевой слой проверяет все redirect-адреса, не принимает поддельный TLS-сертификат, не хранит cookies и не включает сетевые учётные данные.

Добавлены 75 автономных тестов с локальным HTTP/TLS-сервером, скрипт запуска и JSON-отчёт. Версия сборки читается из windows/VERSION; скрипт добавляет реальный Git-хеш и dirty. Обновлены оба README; в main изменена только документация о стадии Windows (62839d2). Swift-код, macOS-тесты/скрипты/ресурсы/документы и корневой VERSION не менялись.

Результат: 75/75, Release-сборка без предупреждений и ошибок, Windows x64 (build 26200), NTFS, SDK 10.0.403. Проверены также потоковая обработка до окончания ответа, связка API с движком, отмена на границе проверки и реальная блокировка файла Windows. Подробности — [отчёт этапа](docs/TEST-RESULTS.ru.md).

Ограничения: нет UI и установщика, не проверен живой API; защита от подмены пути и параллельных запусков, обработка конфликтных поддеревьев, exFAT/SMB и большие реальные загрузки относятся к следующим этапам. Тег и GitHub Release не создаются.
